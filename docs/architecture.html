01 The detection pipeline

A vision model asked to find defects in a full-resolution image misses small ones — a sixth finger occupies a few hundred pixels in a two-megapixel frame. The pipeline's central move is to separate noticing from judging, and to give each stage the resolution its job actually needs.

Every stage speaks in grid cells, never pixels. The model emits C4; tested code converts that to a crop box. Spatial reasoning stays inside logic that can be checked.

02 Who may close a defect

A review tool where anyone can tick "fixed" degrades into a checklist. Here resolution is an act the agent performs, not a claim a human makes: a reviewer uploads a corrected version and the Re-checker compares before and after crops of that defect's region.

Each project has exactly one Brand Owner — the single accountable member who answers guideline questions, approves memory rules, and owns false positives. Two escape hatches exist for them alone, and both leave a record.

03 Deployment

One Cloud Run service serves the API and the built Vue app from a single origin. That removes CORS, a second deployment, and every cross-site cookie problem that comes with splitting them.

04 Does the pipeline beat a single prompt?

The whole design rests on one claim, so it is measured rather than asserted. The baseline is the same model, the same guidelines, and the same gridded image in a single call — what a competent developer would build in an afternoon. What it does not get is the zoom pass, the self-check, or the gate.

The eval set is currently 10 images and 12 labelled defects, and the labels are not exhaustive — so precision is a lower bound, not a measurement: every real defect nobody labelled scores against the pipeline. Verified by inspection on one image, where it correctly flagged malformed wheel-rim spokes and melted windshield wipers, both unlabelled and both counted as false positives. On the clean images, where ground truth is genuinely complete, it produced one finding across four images. And with 12 defects, one defect is worth 8.3 recall points — the lift is not yet resolvable against a 10-point threshold.

05 Decisions worth defending

  • Cell references at every model boundary. Models emit C4, never pixel coordinates. Conversion happens in tested code, so a hallucinated reference is dropped rather than silently drawing a circle in the wrong place.
  • The self-check loop runs in Python, not an ADK LoopAgent. Each iteration must re-render the image before the model can look again — the feedback signal is pixels, not text, which a text-passing loop primitive cannot carry.
  • Dismissals are logged, never deleted. The record of what the agent considered and rejected is what makes its judgement auditable instead of merely confident.
  • Guidelines are never compiled. A brand document goes to the model as written. Where it is ambiguous the agent interviews the Brand Owner at upload time and appends the answers verbatim, rather than summarising a rulebook into something lossy.
  • A fix must carry an image. Claiming fix_submitted without uploading a version is rejected — otherwise a defect waits forever for a re-check with nothing to check.
